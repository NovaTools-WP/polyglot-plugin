Comprehensive multilingual add-on for NovaTools — language management, content translation, string translation, PO/MO editing, WooCommerce multilingual, and WPML migration.

== Description ==

**NovaTools - Polyglot** is a powerful and comprehensive multilingual add-on designed specifically for the NovaTools ecosystem. It empowers you to break language barriers and reach a global audience with advanced language management, content and string translation, seamless WooCommerce integration, and smooth WPML migration capabilities.

⚠️ **IMPORTANT:** This is an add-on plugin. **NovaTools** must be installed and active for this plugin to function.

### 🚀 Unleash the Power of Multilingual Content

*   **Advanced String Translation**: Easily discover, manage, and translate hard-coded strings from themes and plugins directly in the WordPress admin area. Our automatic string scanning and Translation Memory make localization a breeze.
*   **Built-in PO/MO File Editor**: Forget external desktop tools! Manage your translations effortlessly with our powerful built-in PO/MO file editor. Extract strings, parse, compile, and manage `.po` and `.mo` files without ever leaving your WordPress dashboard.
*   **Comprehensive WooCommerce Support**: Take your online store global. Deep integration with WooCommerce allows you to translate products, variations, custom fields, and transactional emails seamlessly. Keep your product synchronization intact across all languages.
*   **Effortless WPML Migration**: Looking for an alternative to WPML? NovaTools Polyglot provides a robust API shim (`WpmlApiShim`) to ensure smooth migration. Third-party plugins that rely on WPML will continue to function flawlessly.
*   **Intuitive Content Translation**: Translate posts, pages, custom post types, terms, and custom fields through a clean and user-friendly interface.
*   **Flexible Language Switchers**: Beautifully integrate language switchers into your site using blocks, widgets, shortcodes, navigation menus, or the admin bar.
*   **Headless Ready with REST API**: Complete REST API support ensures your multilingual content is accessible for headless setups and advanced external integrations.

Take your WordPress site to the next level with professional, marketing-focused multilingual capabilities. NovaTools Polyglot is your ultimate solution for a truly global web presence.

== Installation ==

1.  Ensure you have the main **NovaTools** plugin installed and activated on your WordPress site.
2.  Download the `novatools-polyglot` plugin zip file.
3.  Go to your WordPress Admin dashboard -> **Plugins** -> **Add New** -> **Upload Plugin**.
4.  Upload the zip file and click **Install Now**.
5.  Click **Activate Plugin**.
6.  *Note: If the NovaTools core plugin is not active, you will see an admin notice prompting you to install/activate it.*

== Frequently Asked Questions ==

= Does this plugin require NovaTools to work? =
Yes, NovaTools - Polyglot is an add-on plugin. The main NovaTools plugin must be installed and activated for Polyglot to function properly.

= Is this a good alternative to WPML? =
Absolutely! We've built NovaTools Polyglot to be a powerful and lightweight alternative to WPML, complete with a compatibility layer that ensures your existing WPML-dependent plugins continue to work smoothly during and after migration.

= Does it support WooCommerce? =
Yes, it includes comprehensive support for WooCommerce, allowing you to translate products, variations, emails, and keep your inventory synchronized across different languages.

= How do I translate strings in themes and plugins? =
You can use the built-in String Translation interface to scan themes and plugins for hard-coded strings and translate them directly from your WordPress dashboard, or use our built-in PO/MO file editor.
